# pf_pgv100_ros_package
This ROS package provides a driver for integrating the Pepperl+Fuchs PGV100-F200-R4-V19 optical reading head into ROS-based systems. This sensor is designed for non-contact positioning using Data Matrix code, offering precise position detection in both X and Y directions. This driver facilitates communication over the RS-485 interface, enabling high-resolution and accurate positioning data acquisition within ROS environments.

![Image](https://github.com/user-attachments/assets/67937f95-aff3-46e6-aa5f-c6cfba93596e)



# Usage:

This driver is intended for developers and engineers looking to integrate the PCV100-F200-R4-V19 optical reading head into their ROS-based automation or robotic systems. It provides the necessary interfaces and tools to facilitate seamless communication and data exchange between ROS and the device.
